    Starlink¶

    Client for Starlink's public Modified ITC ephemerides.

    StarlinkClient¶

    StarlinkClient ¶

    StarlinkClient(base_url: str = None, cache_max_age: float = None, max_retries: int = None, rate_limit: RateLimitConfig = None)

    Client for Starlink's public Modified ITC ephemerides.

    Requests are blocking, rate limited (1000 per minute and 30000 per hour by default), retried on transient failures, and honour BRAHE_NETWORK_MODE. The manifest is cached under $BRAHE_CACHE/starlink/MANIFEST.txt for the default base URL, or under $BRAHE_CACHE/starlink/mirrors/<label> for any other base URL so clients pointed at different mirrors never share a cache, and re-fetched with a conditional GET once it is older than cache_max_age; when the listing changes, the prior copy is kept as MANIFEST.previous.txt so the caller can ask which satellites moved. The cache directory is not coordinated across processes or across clients sharing it; run one bulk download at a time.

    Parameters:

    Name Type Description Default
    base_url str

    Custom base URL for testing or a mirror.

    		 None
    cache_max_age float

    Seconds a cached manifest is served without a refresh. Default: 3600.0.

    		 None
    max_retries int

    Extra attempts after the first on transient failures. Default: 3.

    		 None
    rate_limit RateLimitConfig

    Custom per-minute and per-hour request caps.

    		 None
    Example 
    1
2
3
4
5
    import brahe as bh

client = bh.StarlinkClient()
manifest = client.get_manifest()
traj = client.get_trajectory(manifest[0].norad_cat_id)

    download_all method descriptor ¶

    download_all(concurrency: int = 8) -> list[str]

    Downloads every file the manifest lists that is not already cached, using up to concurrency threads that share the rate limiter.

    The full manifest is about 11,100 files and about 22 GB, so a first run against the public mirror is a long transfer. Stops at the first failure and returns it. Files already cached are not re-fetched. No files are pruned; superseded files for a satellite whose file is downloaded are still evicted. Call prune_cache to remove files the manifest no longer lists.

    Parameters:

    Name Type Description Default
    concurrency int

    Worker threads, at least 1. Default: 8.

    		 8

    Returns:

    Type Description
    list[str]

    list[str]: Cache path of one file per listed NORAD ID, in manifest order.

    Raises:

    Type Description
    BraheError

    The first failure, or concurrency == 0.

    get_manifest method descriptor ¶

    get_manifest() -> StarlinkManifest

    Returns the manifest, serving the cached copy while it is younger than cache_max_age and refreshing it with a conditional GET otherwise.

    BRAHE_NETWORK_MODE applies as for the other clients: offline serves a cached manifest of any age, offline-strict serves only a fresh one and rejects a stale or missing one, and a refresh that fails is an error rather than a silent fall back to the stale copy.

    StarlinkManifestEntry¶

    StarlinkManifestEntry ¶

    StarlinkManifestEntry()

    One line of the Starlink manifest with the epochs decoded from the name.

    ephemeris_start has minute resolution (the file name carries only DDDHHMM); its year comes from ephemeris_stop when Starlink's metadata field decodes as GPS seconds, otherwise from the manifest's reference epoch.
