IGS Products¶

Client for the IGS precise product archives, and the types that describe the products it lists.

IGSProductsClient¶

IGSProductsClient ¶

IGSProductsClient(source: IGSProductSource | str, base_url: str = None, cddis_username: str = None, cddis_password: str = None, cache_max_age: float = None, max_retries: int = None, rate_limit: RateLimitConfig = None)

Client for IGS precise-product archives.

The client reads from one IGSProductSource and never falls back to another. CDDIS requires NASA Earthdata credentials, passed as cddis_username and cddis_password. Credentials are sent only to the NASA Earthdata login service and are never shown by repr.

Requests are blocking, limited to 60 per minute and 3600 per hour unless rate_limit sets other caps, retried on transient failures, and honour BRAHE_NETWORK_MODE. Listings and downloaded files are cached under get_igs_cache_dir(). Listings are cached per source, so a client with a different base_url shares the listing cache of the source it stands in for. The cache directory is not coordinated across processes or across clients sharing it.

Parameters:

Name Type Description Default
source IGSProductSource | str

Archive to read from, or its name ("CDDIS", "GARNER", "BKG", case-insensitive).

 required
base_url str

Directory URL that contains one subdirectory per GPS week, for mirrors and tests. A trailing / is added when missing.

 None
cddis_username str

NASA Earthdata username. Requires cddis_password, the CDDIS source, and no base_url.

 None
cddis_password str

NASA Earthdata password. Requires cddis_username.

 None
cache_max_age float

Seconds a cached directory listing is served before it is refreshed. Default: 3600.0.

 None
max_retries int

Extra attempts after the first on transient failures. A retry waits for an exponential backoff with jitter, or for the server's Retry-After when that is longer, up to 30 seconds. Default: 3.

 None
rate_limit RateLimitConfig

Per-minute and per-hour request caps. Each attempt to fetch a listing or a file counts as one request. Default: 60 per minute and 3600 per hour.

 None

Raises:

Type Description
ValueError

If only one credential is given, credentials are given with a non-CDDIS source or with base_url, or source is not a known source name.

download method descriptor ¶

download(product: IGSProduct) -> str

Downloads a product into the cache and returns the cached path.

Files are cached under <cache_dir>/<source>/<week>/<name>, with the source in lowercase, the product's four-digit archive week, and the name as published. A cached file is returned without a request and without an age check. When the file is not cached, BRAHE_NETWORK_MODE must allow the request. A CDDIS download signs in to NASA Earthdata with the client's credentials.

Parameters:

Name Type Description Default
product IGSProduct

Product to download, as returned by a listing.

 required

Returns:

Name Type Description
str str

Path of the cached file, compressed as published.

Raises:

Type Description
BraheError

If the file does not exist on the source, the network mode forbids the request, the Earthdata login fails, the body does not match the name's compression, or the cache cannot be written.

download_sp3_range method descriptor ¶

download_sp3_range(start: Epoch, end: Epoch, center: IGSAnalysisCenter | str, solution: IGSSolutionType | str, *, pad: bool = True, sampling: float = None, concurrency: int = 4) -> list[SP3]

Downloads and parses the daily SP3 orbit files of one analysis center and solution that cover [start, end].

The files are the daily orbit files of every GPS day from the day containing start through the day containing end. With pad set, the days before and after are added when the source has their files, so that SP3Satellite.from_files uses centered fits at the span edges. From GPS week 2238 each day's file is the long-name one-day ORB SP3 file starting at 00:00; when several sampling intervals are published, the coarsest is used unless sampling is set, in which case only that interval is used. Before GPS week 2238 it is the short-name daily SP3 file, such as cod21003.sp3, and sampling is ignored. A solution code that is not a known type is kept as an Other value and matches only files published with that code, so a misspelled code finds no file for the first day of the span and raises.

Every file is chosen, and every listing and selection error is raised, before anything is downloaded. Ultra-rapid orbits are rejected because successive issues overlap in time. A day inside the span with no file is an error; such a padding day is skipped. A padding file that is listed but whose download answers 404 is also skipped, and its day is left out of the result; any other failure to download or parse a padding file, and any failure for a file inside the span, including a 404, is an error.

The files are downloaded and parsed on up to concurrency threads, which share the client's rate limiter. Once a file fails, no further file is started, and the error raised is that of the earliest file that failed. CDDIS requests run one at a time until one has succeeded, so that the threads share one Earthdata session.

Parameters:

Name Type Description Default
start Epoch

Start of the time range.

 required
end Epoch

End of the time range, inclusive.

 required
center IGSAnalysisCenter | str

Analysis center or its code, for example "COD".

 required
solution IGSSolutionType | str

Solution type or its code, for example "FIN".

 required
pad bool

Add the days before and after the span when available. Default: True.

 True
sampling float

Sampling interval of the long-name files to use, seconds. Default: the coarsest published.

 None
concurrency int

Threads that download and parse the files, at least 1. Default: 4.

 4

Returns:

Type Description
list[SP3]

list[SP3]: Parsed daily files in time order.

Raises:

Type Description
BraheError

If solution is ultra-rapid, end is before start, concurrency is 0, a week listing containing part of the span cannot be obtained, a day inside the span has no file on the source (including when its week directory answers 404), or a download or parse fails other than a 404 for a padding file; a parse error names the product.
Example 
1
2
3
4
5
6
7
import brahe as bh

client = bh.IGSProductsClient("GARNER")
start = bh.Epoch(2024, 11, 11, 0, 0, 0.0, 0.0, time_system=bh.GPS)
end = bh.Epoch(2024, 11, 12, 0, 0, 0.0, 0.0, time_system=bh.GPS)
files = client.download_sp3_range(start, end, "COD", "FIN")
satellites = bh.SP3Satellite.from_files(files)

list_products method descriptor ¶

list_products(epoch: Epoch, *, center: IGSAnalysisCenter | str = None, solution: IGSSolutionType | str = None, content: IGSContentType | str = None, format: IGSFileFormat | str = None) -> list[IGSProduct]

Lists the products in the GPS week directory containing epoch.

Files whose names parse as IGS product names are returned; other files are skipped. Each filter left as None matches every product. A center, solution, content, or format code that is not a known type is kept as an Other value and matches only products published with that code, so a misspelled code matches nothing.

Parameters:

epoch Epoch

Any instant in the GPS week to list.

 required
center IGSAnalysisCenter | str

Analysis center or its code, such as "COD".

 None
solution IGSSolutionType | str

Solution type or its code, such as "FIN".

 None
content IGSContentType | str

Content type or its code, such as "ORB".

 None
format IGSFileFormat | str

File format or its code, such as "SP3".

 None

Returns:

Type Description
list[IGSProduct]

list[IGSProduct]: Matching products in listing order.

Raises:

Type Description
BraheError

If the week directory does not exist on the source, or the listing cannot be served from the cache or fetched.
Example

2
3

5

list_products_between method descriptor ¶

list_products_between(start: Epoch, end: Epoch, *, center: IGSAnalysisCenter | str = None, solution: IGSSolutionType | str = None, content: IGSContentType | str = None, format: IGSFileFormat | str = None) -> list[IGSProduct]

Lists the products whose coverage overlaps [start, end].

A product covers [start_epoch, start_epoch + span). A product with no span, such as a short-name weekly file, covers the GPS week of its archive directory. The week directories containing start through end are listed, plus those holding products that begin up to three days before start or are filed up to one day after end. Such an extra week that does not exist on the source is skipped. When BRAHE_NETWORK_MODE forbids fetching a listing, the extra weeks are served only from the cache and skipped when they are not cached; a week containing part of the range must still be cached.

A center, solution, content, or format code that is not a known type is kept as an Other value and matches only products published with that code, so a misspelled code matches nothing.

Solution type or its code, such as "FIN".

Content type or its code, such as "ORB".

save method descriptor ¶

save(product: IGSProduct, destination: str, keep_cached: bool = False, decompress: bool = False) -> str

Downloads a product, if it is not cached, and writes it to destination.

A path with an extension is the file written. An existing directory, or a path whose last component has no extension, is a directory, created if missing, that receives the file under its published name. The file is written as published unless decompress is set, which decompresses a gzip or Unix-compressed (.Z) product and drops the .gz or .Z suffix from the name used in a directory.

Parameters:

product IGSProduct

 required
destination str

Directory or file path, outside the cache directory; any os.PathLike is accepted.

 required

Leave the cached file in place; otherwise it is removed and a later download fetches it again. Default: False.

 False
decompress bool

Write a compressed product decompressed. Default: False.

 False

Returns:

Name Type Description
str str

Path written.

Raises:

Type Description

get_igs_cache_dir¶

get_igs_cache_dir builtin ¶

get_igs_cache_dir() -> str

Get the IGS product cache directory path.

Returns the path to the IGS cache subdirectory used for storing downloaded IGS products. Defaults to ~/.cache/brahe/igs (or $BRAHE_CACHE/igs if environment variable is set).

The directory is created if it doesn't exist.

Returns:

Name Type Description
str str

Path to the IGS cache directory.

Raises:

Type Description
IOError

If the cache directory cannot be created or accessed.
Example 
1
2
3
4
import brahe as bh

path = bh.get_igs_cache_dir()
print(f"IGS cache: {path}")
Note

The directory will be created on first access if it doesn't exist.
