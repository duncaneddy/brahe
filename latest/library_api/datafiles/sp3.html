SP3¶

Reader, writer, and in-memory builder for SP3 precise orbit files.

SP3¶

SP3 ¶

SP3(satellites: Any, epoch_interval: Any, header: Any = None)

An SP3 precise orbit file held in memory.

Read SP3-a through SP3-d files, build files epoch by epoch, and write SP3-d text. All values are SI. The file stores satellites in header order and records on a fixed epoch grid. Properties and accessors return copies; to change the header or a record, modify the copy and assign it back with sp3.header = header or sp3.set_record(...).

import brahe as bh
import numpy as np

sp3 = bh.SP3(["G01", "G02"], 900.0, bh.SP3Header(agency="TEST"))
t0 = bh.Epoch(2024, 11, 10, 0, 0, 0.0, 0.0, time_system=bh.GPS)
sp3.set_record("G01", t0, bh.SP3Record(np.array([15.0e6, 20.0e6, 5.0e6]), clock=2.5e-5))

parsed = bh.SP3.from_str(sp3.to_string())
assert parsed.num_epochs == 1
assert abs(parsed.record("G01", t0).clock - 2.5e-5) < 1e-12

from_trajectories staticmethod ¶

from_trajectories(trajectories: list[tuple[str | SP3SatelliteId, OrbitTrajectory]], step: float = None, header: SP3Header = None) -> SP3

Build an SP3 file from orbit trajectories.

Without step, the file holds the epochs the trajectories store: the trajectories must store the same epochs, to within 1 ms, on a regular grid whose interval is the spacing of the first two. With step, each trajectory is interpolated at start + k * step over the span all trajectories cover, from the latest first epoch to the earliest last epoch. States are converted to ITRF. Velocities are stored when header.has_velocity is set. Clocks and clock rates are absent and are written as the format's bad-clock value unless set with set_clocks and set_clock_rates. The file type follows the satellite systems.

A propagator supplies the trajectory it has propagated as propagator.trajectory, and an SP3Satellite supplies one with to_trajectory().

SP3Satellite¶

SP3Satellite ¶

SP3Satellite()

Orbit and clock samples of one satellite from SP3 data.

Only epochs where the satellite has a valid position are kept, and records() holds one SP3Record per epoch of epochs(). Positions and velocities are in the file's Earth-fixed frame (ITRF), in m and m/s.

The satellite is an orbit state provider with the same state_* and states_* methods as OrbitTrajectory, named after its identifier (such as "G01"), so it can be passed to location_accesses. A state is interpolated in ITRF with a Lagrange polynomial of degree interpolation_degree through the samples around the requested epoch, as centered as the samples allow; a satellite with fewer samples uses all of them. The velocity is interpolated from the records when every sample of the fit has one, and is the derivative of the position polynomial otherwise. A request before the first sample or after the last one raises BraheError, as does any request to a satellite with a single sample.

Missing samples do not stop interpolation: a state between two samples that are further apart than the epoch interval is fitted through the samples around the hole and loses accuracy as the hole grows. gaps() lists those holes.
